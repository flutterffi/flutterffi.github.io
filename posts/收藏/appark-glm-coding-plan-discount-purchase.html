GLM 模型及Coding Plan介绍

智谱AI GLM Coding Plan 是一款专为 AI 编程打造的订阅套餐,由清华大学计算机系技术成果转化而来。该套餐基于智谱最新的旗舰模型 GLM-5.1(前身为GLM-4.7、GLM-4.6),月费最低仅需 49 元,就能在 Claude Code、Cline、Cursor、Roo Code、Kilo Code 等 10+ 款主流 AI 编程工具中畅享智能编码体验。

GLM-5.1 是智谱 AI（Zhipu AI）在 2026 年 4 月 正式发布的下一代旗舰级大语言模型。它被定义为首个专为"智能体工程（Agentic Engineering）"设计的国产基座模型，标志着大模型从"对话框交互"全面转向"自主任务执行"。

参数规模： 总参数量约为 754B，单次推理激活参数量仅为 40B。

上下文窗口： 原生支持 200K（约 202,752 tokens）长上下文，能够一次性吞下整个中型项目的代码库。

推理模式： 默认启用 "思考模式（Thinking Mode）"。模型在输出最终答案前会进行类似人类的"思维链"推演，支持生成最高 128K 的中间推理过程。

技术创新： 集成了 DeepSeek Sparse Attention (DSA) 和 Multi-head Latent Attention (MLA)，在长文本场景下的显存占用比前代降低了近 40%。

常见问题

Q1:GLM Coding Plan 支持哪些模型？

A: 目前支持 GLM-5.1（最新旗舰）、GLM-4.7 和 GLM-4.6。所有套餐均可使用全部模型，新模型发布后会持续更新。

Q2:MCP 工具是否需要额外付费？

A: MCP 工具包含在套餐内，不需要额外付费，但有月度额度限制。联网搜索+网页读取：Lite 100次/月、Pro 1,000次/月、Max 4,000次/月。视觉理解共享套餐的5小时 prompt 额度。额度用完后需等待下月刷新。

Q3:包季/包年如何计费？

A: 连续包季享9折优惠，包年享7折优惠。例如 Pro 套餐月付 ¥149，包季 ¥134/月，包年约 ¥104/月。

Q4:用量是如何计算的？

A: 智谱采用5小时滚动窗口 + 7天周期双重限制。Lite：~80 prompts/5h、~400/周；Pro：~400 prompts/5h、~2,000/周；Max：~1,600 prompts/5h、~8,000/周。每个 prompt 约触发15-20次模型调用。注意：调用 GLM-5 消耗3倍额度（仅 Pro/Max 可用）。

Q5:可以随时升级套餐吗？

A: 可以。你可以随时从低档升级到高档套餐，差价按剩余天数折算。
